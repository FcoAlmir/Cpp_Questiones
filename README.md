# Cpp_Questions 🧠💻

A repository dedicated to practicing **competitive programming in C++**, with solutions to problems solved on:

- 🟠 [Beecrowd](https://www.beecrowd.com.br/)
- 🔵 [Codeforces](https://codeforces.com/)
- 🟢 [LeetCode](https://leetcode.com/)

## 📁 Repository structure

```
Cpp_Questiones/
├── Beecrowd/       # Solutions to Beecrowd problems (formerly URI)
├── CodeForces/      # Solutions to Codeforces problems
├── Contests/        # Solutions written during contests
├── LeetCode/         # Solutions to LeetCode problems
└── README.md
```

Each folder contains the `.cpp` files for solved problems, usually named after the problem's number or identifier on the respective platform.

## 🎯 Goal

This repository serves as a record of study and progress in:

- Data structures (arrays, lists, queues, stacks, graphs, etc.)
- Classic algorithms (searching, sorting, dynamic programming, greedy, etc.)
- Time and space complexity
- Problem-solving under time pressure (contests)

## ⚙️ How to compile and run

Most solutions can be compiled directly with `g++`:

```bash
g++ -std=c++17 -O2 -o solution file.cpp
./solution
```

## 📌 Status

This repository is continuously updated as new problems are solved.
